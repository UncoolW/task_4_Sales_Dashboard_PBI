#  Sales & Order Analysis Dashboard (Power BI)

A data visualization project built using Power BI to analyze sales performance, customer order trends, and regional performance using the Kaggle Sales Forecasting dataset.


##  Dataset

**Source:** [Sales Forecasting Dataset – Kaggle](https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting)


##  Objective

To design an interactive dashboard that:
- Tracks total sales and orders
- Identifies top-performing regions and segments
- Analyzes trends over time
- Offers insights for decision-making


##  Dashboard Features

-  **KPI Cards**: Total Sales, Total Orders, Average Order Value
-  **Time Series Line Chart**: Sales trends over time
-  **Stacked Bar Chart**: Region-wise segment performance
-  **Slicers**: Region, Category, Order Date for interactivity

##  Key Insights

- 📈 Sales peak seasonally with spikes in 2015 and 2017
- 👥 Consumer segment leads across all regions
- 🌍 West and East regions generate the most revenue
- 💵 Average order value holds steady (~0.23K)
- 📊 Sales trends reflect consistent demand across years
